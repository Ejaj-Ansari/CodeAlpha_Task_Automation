# CodeAlpha Task Automation

A simple Python automation project developed as part of the CodeAlpha Python Programming Internship.

## About the Project

This project automatically identifies JPG image files from the current folder and moves them into a separate folder called `JPG_Files`.

The project demonstrates how Python can be used to automate repetitive file management tasks.

## Features

- Automatically detects JPG files
- Creates the destination folder automatically
- Moves JPG files using Python
- Handles multiple JPG files
- Simple command-line output
- Prevents the need for manual file organization

## Technologies Used

- Python
- os module
- shutil module
- File handling
- For loop
- If conditions

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Place some `.jpg` files inside the project folder.
4. Run:

```bash
python task_automation.py
